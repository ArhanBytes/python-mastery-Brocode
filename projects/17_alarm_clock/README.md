# ⏰ Alarm Clock

A simple command-line Alarm Clock built using Python.
This program allows the user to set a specific time and plays a sound when the time is reached.

---

## 📌 What It Does

* Takes alarm time input from the user (HH:MM:SS format)
* Continuously checks the current system time
* Matches current time with alarm time
* Plays a sound when the alarm triggers
* Stops after the alarm sound finishes

---

## ▶️ How To Run It

1. Make sure Python 3 is installed.
2. Install required library:

```bash
pip install pygame
```

3. Place your sound file correctly in the project folder.
4. Run the program:

```bash
python alarm_clock.py
```

5. Enter time in format:

```
HH:MM:SS
```

Example:

```
07:30:00
```
