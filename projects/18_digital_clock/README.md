# 🕒 Digital Clock (PyQt5 GUI)

A modern digital clock built using PyQt5.
This application displays the current time in real-time with a custom font and styled interface.

---

## 📌 What It Does

* Displays current system time (HH:MM:SS AM/PM)
* Updates time every second
* Uses a custom digital font
* Styled with CSS (dark background + neon text)
* Runs as a GUI application

---

## ▶️ How To Run It

1. Make sure Python 3 is installed.
2. Install PyQt5:

```bash id="7c9k2f"
pip install PyQt5
```

3. Make sure the custom font file path is correct.
4. Run the program:

```bash id="q1m4zs"
python digital_clock.py
```

---

## 🧠 Concepts Used

* Classes (OOP)
* PyQt5 (GUI framework)
* QLabel, QWidget, Layouts
* QTimer (real-time updates)
* QTime (current time)
* Signals & Slots
* Styling (CSS in PyQt)
* Custom Fonts (QFont, QFontDatabase)
